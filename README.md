공공 업무추진비 데이터를 기반으로 서울 및 경기 지역의 검증된 맛집을 추천하는 웹 애플리케이션의 AI 챗봇

----------------------------------------------------------------------------------------------------------------

RAG 기술 사용
데이터베이스 준비: 맛집 데이터를 build_db.py 스크립트를 통해 AI가 검색하기 용이한 Vector DB로 변환
실시간 검색 및 답변: 사용자의 질문이 들어오면, 챗봇 서버는 Vector DB에서 가장 관련성 높은 맛집 정보를 실시간으로 검색
답변 생성: 검색된 정보를 바탕으로, 파인튜닝된 언어 모델(LLM)이 자연스러운 추천 문장을 생성하여 사용자에게 전달
AI는 메인 데이터베이스에 직접 접속하지 않고 빠르고 정확하게 최신 정보를 반영하여 답변

----------------------------------------------------------------------------------------------------------------

1. 환경 설정 
pip install -r requirements.txt

2. AI 전용 데이터베이스 생성
python build_db.py

3. 챗봇 API 서버 실행
uvicorn reg_app.py:app --reload
